# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users record and view their expenses. The project was improved using CSS to create a clean, professional, and user-friendly design.

## Project Files

### index.html

The `index.html` file contains the structure of the Budget Tracker, including:

* Page heading
* Add Expense form
* Expense name input
* Amount input
* Category selection
* Date input
* Add Expense button
* Expense table

### style.css

The `style.css` file controls the visual design of the application. It includes:

* A consistent blue and white color palette
* Google Fonts for improved typography
* Styled headings and buttons
* Styled form inputs and labels
* Table borders and spacing
* Alternating table row colors
* Rounded corners
* Margins and padding
* Card-style sections
* Responsive design for smaller screens

## Visual Design

The application uses a blue, white, and light-gray color palette to create a clean and professional appearance.

The page heading, Add Expense form, and Expense Table are presented as separate cards using padding, margins, borders, and border-radius.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
